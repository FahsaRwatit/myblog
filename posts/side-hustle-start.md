# 副业探索第一步

## 为什么要做副业

不是为了「财务自由」这种宏大叙事，就是想多一条收入来源，让生活的容错率高一点。

## 方向筛选

我考虑过几个方向：

1. **技术博客变现** — 周期长，适合长线
2. **接外包项目** — 变现快，但精力有限
3. **AI 工具开发** — 风口期，技术壁垒相对低
4. **课程/知识付费** — 需要积累影响力

最终选择从 **AI 工具开发** 切入，原因是本职后端、Python 基础够用、市场需求真实存在。

## 第一个月行动清单

```
Week 1: 调研 3 个潜在需求方向
Week 2: 做出 MVP，发到闲鱼测试反应
Week 3: 根据反馈迭代
Week 4: 复盘数据，决定是否继续
```

## 目前进展

闲鱼上传了第一个工具（PDF 批量处理），定价 ¥9.9。第一周：**3 单**。

不多，但是真实的市场反馈。

> 开始比完美更重要。
